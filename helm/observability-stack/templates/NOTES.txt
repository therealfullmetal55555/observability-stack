A note on cost
--------------
    collector.customBinary is false, so the tokencost processor is NOT in the
    pipeline. Agents still report their own cost, but the central price table is
    inactive and no cost is filled in for them.

    To enable it:
      docker build -f docker/Dockerfile.collector -t <registry>/otelcol-ai:{{ .Chart.AppVersion }} .
      docker push <registry>/otelcol-ai:{{ .Chart.AppVersion }}
      helm upgrade {{ .Release.Name }} . -n {{ .Release.Namespace }} \
        --set collector.customBinary=true \
        --set collector.image.repository=<registry>/otelcol-ai \
        --set collector.image.tag={{ .Chart.AppVersion }}
{{- end }}
